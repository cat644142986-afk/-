# Product Atelier 体验原型

直接双击 `index.html` 即可查看，不需要启动 Product Atelier、Vite 或 Python 服务，也不会调用真实模型或改写任何用户数据。

建议依次体验：

1. 左侧三个图标切换创作、会话和成长。
2. 在创作页点击“演示一次生成”。
3. 打开右上或左侧的任务中心，体验“只重试失败项”。
4. 点击“为什么这样设计”查看可解释链路。
5. 进入结果评审，选择结果判断和反馈作用范围。
6. 在成长页点击知识节点、演示成长，并批准或拒绝待审核建议。
7. 在设置页确认唯一知识库与可编辑成品目录的边界。

推荐验收尺寸：1440×900、1280×720、960×600。
