# Product Atelier 修改建议闭环与成品计划（2026-08-26）

> 状态：本文件仅保留 2026-08-26 第一批修复范围与发布记录，不再作为后续执行总计划。实机复验发现跨面板反馈回执、开始下一项和 Growth 投影仍未闭环；完整状态、剩余阶段、验收矩阵与“继续”入口统一见 `docs/product-atelier-master-execution-plan-2026-08-22.md` 的“2026-08-26 实机反馈校准与续作断点”。

## 目标

先关闭 2026-08-25 真实使用反馈中会阻断日常工作的缺陷，再进入智能选物与生图质量两个独立能力里程碑。所有“已完成”都必须有自动测试、生产构建和桌面成品验证证据。

## 修改建议与执行分层

### P0：本轮必须交付

1. 结果态提供明确的“完成这张，开始下一项”主操作；当前结果保留在本地账本，不删除素材或历史。
2. 反馈提交显示处理中状态，成功后把输入区收起为“已记录”回执，并允许补充反馈。
3. 完成任务和历史任务的“查看生成依据”绑定该任务的执行 trace，不再显示实时重新编译的知识。
4. 修复结果评审“小幅调整”提交 `adjust`、后端仅接受 `adjusted` 的新回归。

### P1：本轮一并关闭

1. 结果图片使用严格的容器约束，在窄窗口和高 DPI 下完整显示。
2. 原图与结果比例一致时使用滑块叠加；比例不一致时自动切换为并排完整展示，避免伪对齐。
3. 数字语义统一为“素材库 N 张 / 已选 N 张”，整夹导入也按图片数量显示。
4. 新增纯逻辑回归测试，覆盖反馈信号、任务证据恢复和比较模式选择。

### 后续独立里程碑

1. 智能选物抠图：grounding/检测 → segmentation → 边缘精修 → 蒙版确认；快速去背景继续明确“不理解名称和数量”。
2. 生图质量与速度：建立固定样图、固定模型/参数、耗时、成本和盲评基线，再优化 Prompt、参考图、尺寸与模型路由。
3. 发布级验收：100%/125%/150% DPI、最小窗口、重启恢复、异常态、20 张批量、便携 EXE 冷启动。
