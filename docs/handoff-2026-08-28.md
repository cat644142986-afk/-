## 另一台电脑的开始方式

### macOS、没有任何本地文件

只需在苹果电脑“终端”粘贴这一行；脚本、源码、测试、总计划和本交接文档都从 GitHub 获取：

```bash
/bin/bash -c "$(curl -fsSL 'https://raw.githubusercontent.com/cat644142986-afk/-/refs/heads/codex/master-roadmap-phase-0-1/tools/bootstrap-macos.sh')"
```

完整说明见 `docs/macos-zero-state-handoff-2026-08-28.md`。Mac 可继续跨平台源码开发和离线门禁，但不能替代 Windows 的 EXE、sidecar、NSIS、DWM/DPI、桌面快捷方式和正式便携版验收；不得把 Mac 通过误写成 Windows 正式发布。

### Windows 开发机

```powershell
git clone https://github.com/cat644142986-afk/-.git ProductAtelier-Desktop
cd ProductAtelier-Desktop
git fetch origin
git switch codex/master-roadmap-phase-0-1
git pull --ff-only origin codex/master-roadmap-phase-0-1

npm ci
python -m pip install -r python/requirements.txt
python -m pip install -r python/requirements-test.txt
python -m pip install -r python/requirements-build.txt

npm run test:frontend
python -m unittest discover -s tests -p "test_*.py"
npm run build
cargo check --manifest-path src-tauri/Cargo.toml --features custom-protocol
```

2026-08-28 实测可用的跨电脑同步源是 GitHub `origin`。Gitee 远端的旧 OAuth 已过期并返回 403，本检查点尚未同步到 Gitee；凭据刷新并核对远端提交前，不要从 Gitee 接续本轮。运行任何代码修改前，先读唯一总计划、本文件、`ROLLBACK.md` 和 schema v3 文档；如果新电脑也有个人知识库，再额外读取其全局规则。没有 `D:\知识库` 不阻止按仓库内交接继续产品任务。
